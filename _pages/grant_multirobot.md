## CNS: An Edge-Based Approach to Robust Multi-Robot Systems in Dynamic Environments

### Project Summary

Multi-robot systems operating in dynamic and adversarial environments must be robust to both hardware failures and malicious attacks. This collaborative NSF project develops **edge-based security and reliability mechanisms** for multi-robot systems.

Research contributions include:

- **Secure localization:** Hardware-assisted techniques for tamper-resistant localization in GPS-denied environments
- **Attack detection in robot networks:** Identifying and mitigating address-resolution and communication-layer attacks that target coordinated robot swarms
- **Edge computing integration:** Offloading security-critical computations to lightweight edge hardware while preserving real-time performance
